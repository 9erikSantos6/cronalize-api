# cronalize-api

> **Note:** This API is currently under development. There is no guarantee of stable operation at this time.

The system automates the scheduling of data payloads for delivery to specific destinations at precise future dates and times. This eliminates the need for client applications to manage complex local cron tasks.

## How to Run the API

### Prerequisites
* Node.js v24+
* pnpm v11+

### 1. Clone the Repository
```bash
git clone https://github.com/9erikSantos6/cronalize-api.git
cd cronalize-api
```

### 2. Install Dependencies
```bash
pnpm install --frozen-lockfile
```

### 3. Run the Application
```bash
pnpm dev
```

## How to Build

### Prerequisites
* Installed dependencies (Run `pnpm install` first)

### 1. Build the Project
```bash
pnpm build
```

### 2. Run the Production Build
```bash
pnpm start
```
